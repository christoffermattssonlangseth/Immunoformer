# Paper outline: figures, panels, sources

Figures live in `docs/figures/` (PDF + 300 dpi PNG). Each figure has one script under `analysis/figures/`. Run from the repo root:

```
PYTHONPATH="$PWD:$PWD/scripts:$PWD/analysis" python analysis/figures/collect_data.py   # once
PYTHONPATH="$PWD:$PWD/scripts:$PWD/analysis" python analysis/figures/fig1.py          # ... fig5.py, supp.py
```

`collect_data.py` regenerates the per-animal values that no run saved: LOAO clock predictions, compartment predictions, endothelial Col4 and cell-type proportions. It writes them to `docs/figures/data/animals.csv` and stops with an error if any value does not reproduce the reported ρ. All checks passed:
- RR clock: 0.828
- chronic clock: 0.852
- compartment ρ: 0.832 / 0.820 / 0.932 / 0.758
- none∩terminal gene overlap: 57 (RR) / 72 (chronic)

Conventions:
- one point per animal;
- n and ρ [95% CI] on every correlation panel; CIs are 2000-resample bootstraps over animals;
- RR = blue `#2a78d6`, chronic = orange `#eb6834`.

Results that cannot be interpreted are shown and flagged in the panel title, not left out.

Cohorts: RR n = 33 (30 EAE + 3 CFA); chronic n = 34 (29 EAE + 5 CFA).
